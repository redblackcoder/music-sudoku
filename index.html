Musical Sudoku
Instructions
Solve the Sudoku puzzle using standard Sudoku rules, however, instead of using digits 1–9, use the following musical symbols. Each symbol must appear exactly once in each row, each column, and each 3×3 square.
Quarter Note A filled note head with a stem; lasts 1 beat
Half Note An open note head with a stem; lasts 2 beats
Whole Note An open note head without a stem; lasts 4 beats
Eighth Note A filled note head with a stem and one flag; lasts ½ beat
Quarter Rest A zigzag symbol meaning silence for 1 beat
Beamed Eighths Two eighth notes joined by a beam; each lasts ½ beat
Treble Clef The G-clef; marks the higher-pitched staff
Bass Clef The F-clef with two dots; marks the lower-pitched staff
Sharp The ♯ sign; raises a note by a half step

Musical Sudoku Builder

Press 1-9 to place a music symbol. Click a cell to select it. Press Delete/Backspace to clear.
Use arrow keys to navigate.
